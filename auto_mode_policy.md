# Auto Mode Policy

## Default

Run automatically as much as possible during the early phase.

The system may generate and queue:

- Link-free X posts
- Link-free Threads posts
- Reply guidance without direct affiliate URLs
- note/blog drafts
- product review queues
- weekly analysis reports from exported CSV files

## No-Review Auto-Ready Content

A post can be marked `auto_ready` when:

- It has no external URL
- It has no affiliate URL
- It does not include exaggerated claims
- It does not include explicit medical, financial, or guaranteed relationship outcomes
- It is a complete value post and not a link teaser
- It has passed the pre-publish trend and incident check

## Hold For Review

Hold content for review when:

- It includes a URL
- It includes product names or affiliate links
- It mentions weight loss, investment, money-making claims, medical claims, or guaranteed romance outcomes
- It uses words like 絶対, 必ず, 確実, 100%, 痩せる, 儲かる, 復縁できる
- The pre-publish check finds a disaster, incident, major controversy, or topical mismatch

## Reply Links

Replying to your own post with a link is allowed as the preferred pattern.

Rules:

- Main post must stand alone without the link
- Reply should not be attached to every post
- Use reply guidance after the main post gets early engagement
- Use profile/note links first; direct affiliate links should generally stay inside note/blog pages
- Include PR disclosure when the reply leads to affiliate content

## Posting

Use official platform scheduling or manual posting. Do not imitate human mouse movement or bypass platform detection.

If posting access is not connected, generate the queue files and continue daily.

## Weekly Analysis

Monday generation must read the latest weekly analysis report. If no report exists, Monday output should be marked as draft or hold-for-review.
